# A dashboard query returns a shape the panel doesn't expect

## What happens

Grafana panels assume a data shape: one frame or many, one value per series, labels present or not.
Prometheus answers with one frame per series, and a table shows only the first frame unless frames
are merged; a join on a label fails when one query drops it; `noValue` fills every empty cell, not
just an empty panel; titles get cut in narrow panels. The dashboard looks right with today's data
and misleads with tomorrow's.

## How to spot it

- A table shows one row where the query returns several (Query inspector, Data: several frames).
- A stat panel's count disagrees with the table next to it.
- Text in cells where a value is simply absent.

## How to fix

Add a `merge` transformation before a table's other transformations; aggregate queries to the label
the panel joins on (`max by (host)`); set `noValue` only where an empty panel is the meaning.

## How to prevent

Dashboards are generated, and every panel query is run against live Prometheus and the result looked
at as a rendered screenshot before it's pushed.
