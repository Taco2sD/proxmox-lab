# A default that is reasonable in general is wrong here

## What happens

Defaults are tuned for the common case: nginx verifies one certificate level, the Proxmox provider waits 15 minutes for a guest agent, chrony only steps the clock at startup, Proxmox cloud-init names the NIC `eth0`. In this lab each of those caused an outage or a hang.

## How to spot it

- A wait that lasts exactly a round number of minutes (a timeout default).
- A failure only in this lab's topology (certificate chains, nested clocks, predictable NIC names).

## How to fix

Set the value explicitly where it's used, with a comment saying why the default didn't fit.

## How to prevent

When adopting a tool, list the defaults that touch time, waits, verification and naming, and decide each one.
