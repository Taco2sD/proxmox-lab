# A host missed something every host should have

## What happens

Fleet-wide basics (automatic security updates, a monitoring agent, time sync, log rotation) are
assumed everywhere, but a host built differently (an LXC template, a hand-installed server, the
hypervisor) never got them. Nothing fails, so nothing tells you: the gap shows only as drift, for
example dozens of pending security updates on one machine.

## How to spot it

- Outliers: `sum by (host) (apt_upgrades_pending{origin=~".*-security.*"})`; a host with no `up`
  series at all has no exporter.
- Compare per host: `dpkg -l unattended-upgrades prometheus-node-exporter chrony`.

## How to fix

Put the baseline in one role and apply it to every host type in `ansible/site.yml` and
`ansible/local.yml`, with per-OS differences (Ubuntu; Debian with Proxmox) inside the role.

## How to prevent

Every play lists the baseline roles; a new host joins a play that already has them. Monitoring
compares hosts with each other, so an outlier stands out.
