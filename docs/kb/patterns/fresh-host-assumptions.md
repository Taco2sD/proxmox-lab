# Code that only ever ran on a host prepared by hand

## What happens

Roles written against hosts that were set up by hand assume directories, users or packages a fresh host doesn't have: copying into /usr/local/lib/lab before creating it, writing a key into a .ssh that doesn't exist yet.

## How to spot it

- The first run on a new or rebuilt host fails on a missing directory or user.

## How to fix

Create what you depend on in the same role, before using it.

## How to prevent

Apply roles to a fresh container or VM when they change, and keep hand-made state to a minimum.
