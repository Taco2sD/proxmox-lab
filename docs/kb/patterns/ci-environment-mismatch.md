# CI's environment differs from the lab's

## What happens

GitHub's runners are fresh, unprivileged and checked out from git: no /run/lab, no executable bit unless git records it, no live inventory, deprecated action runtimes. Tests that pass on mgmt01 fail there, or tests depend on live data and block unrelated changes.

## How to spot it

- A check passes on mgmt01 (`/opt/lab-dev`) and fails in GitHub Actions, or the reverse.
- A data-only change (removing a machine) fails a unit test.

## How to fix

Make paths overridable for tests, set modes in git (`git update-index --chmod=+x`), and give tests their own fixtures.

## How to prevent

Run `tools/check` as a normal user from a fresh clone before pushing.
