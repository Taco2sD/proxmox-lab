# Session state held by a browser or client outlives what it points at

## What happens

Browsers and remote-desktop clients keep sessions and credentials and reuse them in ways the server didn't plan for: Guacamole reuses an open session and ignores a new login, a 401 from an application behind Basic auth wipes the browser's cached credentials, mstsc reuses saved credentials after a server redirection.

## How to spot it

- "No recent connections" or the wrong machine after a fresh login.
- The browser asks for credentials it had a moment ago.
- Works in a private window but not in the normal one.

## How to fix

End the old session explicitly before starting a new one, answer 403 instead of 401 behind an auth proxy, and give logins a bounded lifetime.

## How to prevent

Test every flow twice in the same browser, and once after leaving the tab open for an hour.
