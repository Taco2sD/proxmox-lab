## What happens

A network starts out with only admins on it, so everything inside is trusted. Later it
gains machines that other people log in to (visitors' workstations, shared build boxes),
and every management interface (the hypervisor's SSH and API, the domain controller, the
automation host) is now one password guess away from them.

## How to spot it

From a non-admin machine, try connecting to the management ports (22 and 8006 on the
hypervisor, 22 on the DC and runner) and see what answers. Check how those services
authenticate (`sshd -T | grep -E "passwordauthentication|permitrootlogin"`) and whether
anything throttles guessing.

## How to fix

Cheapest first: key-only SSH on management hosts, then a default-deny firewall for the
untrusted machines with an explicit allow-list of the flows they need, then separate
networks (VLAN or bridge) with routing only to the shared services.

## How to prevent

Write the allowed flows down in git as firewall rules when a new kind of user or machine
joins the network, and re-run the reachability test from the new machine.
