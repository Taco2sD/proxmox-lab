# An upstream release changed behaviour the lab relied on

## What happens

A newer firmware, distro, Python or Ansible release changes a default or drops a feature: EDK2 needs an RNG to network boot, ansible-core 2.20's `find` no longer returns `lnk_source`, Python 3.13 rejects certificates without an Authority Key Identifier, Ubuntu socket-activates `ssh.service`, systemd prints OSC 3008 codes. Nothing in the lab changed, yet something stops working or silently does nothing.

## How to spot it

- A step that used to work returns nothing or fails right after an image build or package upgrade.
- Deprecation warnings in Ansible output (they come before removals).
- Compare versions: `ansible --version`, `python3 --version`, `dpkg -l <package>`.

## How to fix

Adapt to the new behaviour instead of pinning the old one, and record in the issue the version where it changed.

## How to prevent

Rebuild the golden image and run the checks regularly so changes show up in one place; make steps fail loudly when they match nothing; read deprecation warnings.
