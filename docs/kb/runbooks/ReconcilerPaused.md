# ReconcilerPaused

## What it means

/var/lib/lab/reconcile.paused has existed for over 4 hours. While it exists the reconciler
does nothing: merged changes aren't deployed and drift isn't repaired. Pausing is right
during manual maintenance (docs/operations.md); forgetting to unpause is the risk.

## First five minutes

1. Since when: `ls -l --time-style=full-iso /var/lib/lab/reconcile.paused` on mgmt01, and
   `cat` it (people often write the reason in it).
2. Is the maintenance still going on? Ask whoever paused it before unpausing.
3. What will run on unpause: `git -C /opt/proxmox-lab fetch -q && git -C /opt/proxmox-lab log --oneline HEAD..origin/stable`.

## Common causes

- Maintenance finished, unpause forgotten.
- A manual test of uncommitted changes (paused so the reconciler doesn't deploy at the
  same time) that ended without cleaning up.

## Escalate / fix

- Unpause: `rm /var/lib/lab/reconcile.paused`. The next run (within a minute) applies
  everything merged meanwhile; watch it with `journalctl -u lab-reconcile -f`.
