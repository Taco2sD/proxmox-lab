# MemoryLow

## What it means

A machine has had under 8% of its memory available (free plus reclaimable cache) for
10 minutes. Next come swapping and the kernel's OOM killer.

## First five minutes

1. `free -m` and `ps aux --sort=-rss | head -15` on the host.
2. mgmt01 (3 GB): `docker stats --no-stream` (Grafana, Prometheus, Guacamole).
3. pve01: the Lab overview's "Memory by VM" panel, `qm list` (MEM column), and how many
   workstations are awake. The portal admits workstations against `guest_memory_mb`
   (ansible/group_vars/all.yml), which leaves room for dc01, mgmt01 and Proxmox itself.
4. Has anything been killed? `journalctl -k -b | grep -i -E 'oom|killed process'`.

## Common causes

- pve01: too many workstations awake, or an image build VM (9009) running beside them.
- A workstation's own work (a devbox has 1 GB).
- A leak in a long-running service: memory rising steadily on the Machine dashboard.

## Escalate / fix

- pve01: hibernate idle workstations (My lab or the admin page); they resume exactly
  where they were. Don't turn memory ballooning back on for workstations: a VM squeezed
  mid-install once deadlocked ("System is deadlocked on memory").
- A leaking service: restart it, then find the cause in its role.
